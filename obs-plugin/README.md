# WebcamGo Direct для OBS

Плагин Windows x64 принимает камеру, экран и звук с передатчика WebcamGo напрямую в OBS. На передатчике запускается обычный режим **Передатчик**.

Проверенная версия OBS — **30.1.2**. Видео декодируется через WIC внутри OBS, а звук поступает в микшер напрямую. Потребление CPU на Intel 5405U и задержка между отдельными источниками пока не измерены.

## Установка и обновления

1. Запусти `WebcamGo-OBS-Direct-Setup-Windows-x64.exe`. Установщик найдёт стандартную OBS или позволит выбрать папку портативной копии.
2. Закрой OBS и нажми **Установить**. Для защищённой папки Windows попросит права администратора на этап замены DLL. После установки можно открыть OBS из окна установщика.
3. В меню «Пуск» открой **WebcamGo Direct — обновления**. Нажми **Проверить обновления**. Загрузку можно выполнить при открытой OBS. Когда пакет проверен, закрой OBS и нажми **Установить обновление**.

Установщик умеет работать без интернета с комплектной версией. Для сетевой проверки нужен доступ к GitHub. При сбое загрузки текущая установка остаётся доступной. После замены **Восстановить предыдущую** возвращает одну сохранённую копию DLL. Сцены, профили и сторонние плагины OBS сохраняются. Если нужно установить плагин вручную, закрой OBS и скопируй `obs-plugins` из обычного ZIP в корень папки OBS.

## Источники OBS

Открой OBS и добавь источники:

| Источник | UDP-порт по умолчанию |
|---|---:|
| WebcamGo Camera | 5001 |
| WebcamGo Screen | 5002 |
| WebcamGo Audio | 5003 |

В свойствах каждого источника нажми **Search local network** и выбери нужный ПК из списка **Network sender**. Камеру, экран и звук можно направить с разных ПК. Список показывает имя компьютера и IPv4-адрес. Для поиска в списке нужен передатчик с поддержкой сетевого обнаружения. Если порты экрана или звука изменены, укажи тот же порт в OBS перед поиском.

Для старого передатчика или сети, в которой broadcast недоступен, выбери **Manual address / automatic** и введи IP. Если передатчик на том же ПК, укажи `127.0.0.1`. Пустой IP подключает первый откликнувшийся передатчик. Для звука плагин принимает готовый микс системы и микрофона. Его уровень виден в микшере OBS.

Для слабого ПК можно ограничить декодирование через **Decode FPS limit** и **Decode scale**. Источники можно добавлять в другие сцены через **Добавить существующий**. Если в сцене остаются прежние источники Teleport, выключи их при проверке, чтобы видеть результат прямого ввода отдельно.

## Сборка

Понадобятся Go из `go-version/go.mod`, Windows x64 [LLVM MinGW](https://github.com/mstorsjo/llvm-mingw/releases), исходники [OBS 30.1.2](https://github.com/obsproject/obs-studio/tree/30.1.2) и установленная или распакованная OBS этой версии. Передай пути в `build.ps1 -Clang <clang.exe> -ObsSdk <obs-studio-30.1.2> -ObsBin <bin/64bit>`. Скрипт использует сетевой код и WIC из Go-версии.

На публичной ветке `obs-native` команда `build.ps1 -PluginOnly` собирает DLL и ZIP для ручной установки. [Лицензия кода плагина](LICENSING.md).

## Канал выпусков

При наличии локальных исходников установщика `build.ps1 -Version 0.1.0-preview.1` собирает DLL с номером версии в ресурсе Windows, отдельный EXE, ZIP обновления и ZIP с лицензиями в `release/obs-direct/v0.1.0-preview.1/`. Обычный ZIP для ручного копирования остаётся в `release/`.

- Используй в [GitHub Releases](https://github.com/bukirev/webcam-low-latency/releases) теги вида `obs-direct-v0.1.0-preview.1` для предварительных версий и `obs-direct-v0.1.0` для стабильных. Флаг **Pre-release** должен совпадать с суффиксом тега.
- Загрузи EXE, `WebcamGo-OBS-Direct-Update-Windows-x64.zip` и `WebcamGo-OBS-Direct-Licenses.zip` под исходными именами. Укажи в описании релиза ссылку на исходники плагина для этого тега. Обновлятор использует точное имя ZIP, размер и SHA-256 из GitHub API. Проверь их перед публикацией выпуска. Предыдущие выпуски оставляй доступными.
- В ZIP формата 1 ровно два файла: `package-info.json` с продуктом, версией, платформой и SHA-256 DLL и сама `webcamgo-direct.dll`. Старые установщики обновляют DLL из этого формата. Для изменения самого обновлятора запускается новый EXE установщика.

Схема следует опыту VB2CCC: получение списка релизов по HTTPS, проверка скачанного пакета, затем локальная замена. Для OBS версия хранится в самой DLL, поэтому установка публикует её одним перемещением с того же диска. Запуск OBS остаётся явным действием. Откат доступен из обновлятора после закрытия OBS. SHA-256 GitHub проверяет целостность загруженного файла. Подпись Authenticode в этой сборке отсутствует.
