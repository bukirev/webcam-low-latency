Webcam Low Latency 4.1 — Windows 10/11 x64
На слабом клиенте включите «Экономия CPU: 20 FPS, JPEG /2» в настройках камеры и во вкладке «Связь» окна экрана.
Готовая версия из Releases работает без Python: распакуйте весь архив вместе с папкой _internal.
START_SCREEN_SERVER.bat — передача экрана, системного звука и микрофона.
START_SCREEN_CLIENT.bat — приём экрана и звука в отдельном окне.
START_SCREEN_LOCAL.bat — локальный просмотр экрана и уровня звука.
Также отдельное окно открывается кнопкой «Экран и звук» в окне камеры.
Нажмите «Старт / применить» на передатчике и приёмнике. Порты экрана/звука: UDP 5002/5003.
Полная инструкция по новой версии и всем настройкам находится в README.md.

Запуск исходного кода:
Распакуйте архив на обоих компьютерах. Нужен Python 3 с tkinter.
При первом запуске BAT установит зависимости (нужен интернет только для установки).
Закройте VLC и другие программы, использующие камеру.
START_LOCAL.bat — локальный просмотр.
START_SERVER.bat — компьютер с камерой, передача исходного изображения JPEG по UDP.
START_CLIENT.bat — второй компьютер, автоматический поиск. Если не работает, введите IPv4 передатчика (ipconfig), подождите несколько секунд.
Разрешите Python в брандмауэре Windows только для частных сетей. Передатчик слушает UDP 5001, приёмник использует динамический UDP-порт. Порт 5000 не используется. Не открывайте порты в интернет. Видео не шифруется, доступно участникам доверенной локальной сети.
Рекомендация: Ethernet, 720p, 30/60 FPS, MJPG, JPEG 75–80. При потерях уменьшите качество JPEG или FPS. Несколько клиентов увеличивают нагрузку на сеть. Пропуски кадров включают отбрасывание устаревших кадров.
Настройки изображения применяются локально к просмотру; аппаратные настройки и разрешение захвата — на передатчике. На клиенте параметры камеры не действуют. Настройки сохраняются отдельно для каждого режима.
F2 — панель, F11 — полный экран, F5 — снимок, Esc — выход из полного экрана или программы.
