# Webcam Low Latency 3.0

Приложение для Windows 10/11: локальный просмотр веб-камеры и передача видео между компьютерами по локальной сети.

## Скачать и запустить

1. Нажмите **Code → Download ZIP** и распакуйте архив.
2. Установите Python 3 с поддержкой tkinter. При установке включите **Add Python to PATH**.
3. Запустите нужный файл:
   - `START_LOCAL.bat` — локальный просмотр камеры.
   - `START_SERVER.bat` — передатчик на компьютере с камерой.
   - `START_CLIENT.bat` — приёмник на другом компьютере.

При первом запуске зависимости OpenCV, Pillow и NumPy устанавливаются автоматически; для установки нужен интернет.

## Передача по сети

Оба компьютера должны находиться в одной локальной сети. Клиент автоматически ищет передатчик; при необходимости укажите IPv4 компьютера с камерой вручную.

Разрешите Python в брандмауэре Windows для частных сетей. Передатчик слушает UDP 5001, клиент использует динамический UDP-порт. Видео не шифруется: используйте доверенную локальную сеть и не открывайте порты в интернет.

Рекомендуемые параметры: Ethernet, 1280×720, MJPG, 30/60 FPS и качество JPEG 75–80. Доступные режимы зависят от камеры.

## Управление

- **F2** — показать или скрыть настройки.
- **F11** — полный экран.
- **F5** — снимок в папку `snapshots`.
- **Esc** — выйти из полного экрана или закрыть приложение.

Обработка изображения применяется к локальному просмотру. Аппаратные настройки камеры задаются на передатчике. Настройки сохраняются отдельно для каждого режима.
